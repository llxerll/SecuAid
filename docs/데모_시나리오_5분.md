# 시큐에이드 — 5분 데모 영상 촬영 대본 (v0.12 · 버튼으로 답하기·지금 가장 먼저·어떻게 하나요?·72시간 대응 차트·증거 확보 도우미·저장·공유 기준)

> 목표: ① 업무 문제 ② **로그를 모르는 담당자도** 따라 할 수 있는 실제 동작 ③ Liner API 5종이 쓰이는 지점이 5분 안에 보이게.
> 모든 데이터는 가상입니다(RFC 5737 IP, `.example` 도메인, 가상 은행·계좌). 실제 회사 자료·개인정보는 쓰지 마세요.

**준비**
1. https://incident-note.vercel.app/ — 오른쪽 위 상태 알약이 **`Liner 연동`**(파란 점)인지 확인
2. 브라우저 전체 화면, 확대 110%. 열려 있는 사건이 있으면 **[새 사건]** 으로 첫 화면에 돌아옵니다.
3. 아래 입력 문장은 메모장에 복사해 두고 붙여넣습니다(타이핑 시간 절약).
4. 데모 재생은 "지금 15분 전에 알았다"로 시작하므로 촬영 날짜와 무관하게 기한 시계가 살아 있습니다.

**강조할 UX 포인트(자막)**
- 시계는 사건을 시작하는 순간부터 돕니다 — 실제로 더 일찍 알았다면 [인지 시각 수정](방금·30분 전·오늘 아침…)
- 질문은 버튼으로 — 타이핑 없이 답하고, 모르면 '모르겠어요'(〔미확인〕으로 남음)
- 맨 위 '지금 가장 먼저' 한 줄 → [했어요] → 다음 일, 모두 끝나면 '문서 초안 만들기'
- 할 일마다 [어떻게?] — 준비물·순서·전화 대본, 없는 건 Liner가 찾아 줌
- [저장·공유] — 카톡 요약 · 마감 달력 알림 · 사건 파일 / 창을 닫아도 '진행 중인 사건'에서 이어 하기
- 오른쪽 위 [사용법] — 그림으로 보는 4단계·화면 구성·자주 묻는 것

**Liner API 5종 — 자막으로 띄울 것**
- `Liner Mark` — 상황 브리핑 · 구어체 해석(유형 · "오늘 오전 10시쯤" 같은 시각 · 있었던 일)
- `Liner Quick Answer` — 유형별 즉답 가이드 · 담당자의 질문에 출처와 함께 답 · 내장 안내가 없는 할 일의 '어떻게 하나요?'
- `Liner Search Agent` + `Liner Search` — 신고 기한 법령 재확인(동시 호출) · 공식 신고 창구
- `Liner Search` — 업체별 로그 확인 공식 안내 찾기(증거 확보 도우미)
- `Liner Visualization` — 0~72시간 사건 차트(격리된 창)
- `규칙 엔진` — 판별·심각도·기한·할 일(같은 입력이면 같은 결과, 응답에 Liner 대기 없음)

**촬영 시 주의**
- Liner 응답(브리핑·법령 재확인·시각화)은 수 초~수십 초 걸립니다. 판정은 이미 화면에 있으니 그동안 다른 장면을 찍고 컷으로 잇습니다.
- 재생 중 대화 영역 위 **[■ 재생 정지]** 로 멈추고 직접 입력을 이어갈 수 있습니다.
- 실제 회사명·계정·고객 정보가 화면에 잡히지 않게 하세요.
