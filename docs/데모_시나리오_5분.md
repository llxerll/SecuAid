# 시큐에이드 — 5분 데모 영상 촬영 대본 (v0.9 화면 기준)

> 목표: ① 업무 문제 ② 에이전트 실제 동작 화면 ③ Liner API가 쓰이는 지점이 5분 안에 보이게.
> 모든 데이터는 가상입니다(RFC 5737 IP, `.example` 도메인, 가상 은행·계좌). 실제 회사 자료·개인정보는 쓰지 마세요.

**준비**
1. 배포 주소 https://incident-note.vercel.app/ (또는 로컬: `.env`에 `LINER_API_KEY` → `python app.py` → `http://127.0.0.1:8000`)
2. 상단 오른쪽 상태 알약이 **`Liner 연동`**(파란 점)인지 확인합니다. 회색 `규칙 기반(키 없음)`이면 키 설정을 다시 확인하세요.
3. 브라우저 전체 화면, 확대 110%. 이전 사건이 열려 있으면 오른쪽 위 **[새 사건]** 으로 첫 화면에 돌아옵니다.
4. 데모는 "지금으로부터 15분 전에 알았다"로 시작합니다. 촬영 날짜와 상관없이 기한 시계가 살아 있습니다.

**강조 포인트(자막)**
- `규칙 엔진` = 판별·심각도·기한·할 일 (LLM 없이 같은 입력이면 같은 결과, 응답에 Liner 대기 없음)
- `Liner Mark` = 상황 브리핑·사실 해석 (chat/completions)
- `Liner Search Agent + Search` = 법령 기한 재확인 + 공식 창구 (동시 호출)
- `Liner Quick Answer` = 10대 유형별 즉답 가이드
- `Liner Visualization` = 0~72시간 사건 차트 (격리된 창에서 실행)

**촬영 시 주의**
- 법령 재확인은 20~30초 걸립니다. 그동안 체크리스트·타임라인 장면을 찍으면 기다리는 장면 없이 이어집니다(판정은 이미 화면에 있음).
- 재생 중 대화 영역 위의 **[■ 재생 정지]** 로 멈추고 직접 입력을 이어갈 수 있습니다.
- [한 번에 실행]은 결과만 보여 주므로 컷 전환용으로만 쓰세요.
- 실제 회사명·계정·고객 정보가 화면에 잡히지 않게 하세요.
