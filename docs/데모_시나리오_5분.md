# 실드메이트 72 — 5분 데모 영상 촬영 대본 (S1 메인 시나리오)

> 목표: ① 업무 문제 ② 에이전트 실제 동작 화면 ③ Liner API가 쓰이는 지점이 5분 안에 보이게.
> 모든 데이터는 가상입니다(RFC 5737 IP, `.example` 도메인, 가상 은행·계좌). 실제 회사 자료·개인정보는 쓰지 마세요.

**준비**
1. `.env` 에 `LINER_API_KEY` 설정 → `python app.py` → `http://127.0.0.1:8000`
2. 상단 툴바의 `데모 시나리오` = `S1. 영업관리 계정 탈취 → 거래처 계좌 변경 사칭`
3. 화면 확대 110%, 브라우저 전체 화면. 대화는 왼쪽, 결과는 오른쪽 `대응 보드` 탭(① 초동대응·법정기한 / ② 판정·타임라인·차트 / ③ 문서 초안)에 나옵니다.
4. 시계를 띄워 두면 "몇 분 걸렸는지" 비교 장면에 좋습니다. 첫 화면의 4대 강점 스트립을 3초 정도 잡아 주면 서비스 가치가 먼저 전달됩니다.

**강조 포인트(자막으로도 넣기)**
- `Liner Mark` = 대화·판단 해석·문장 (chat/completions)
- `Liner Search Agent` = 법령 기한 재확인 + 출처 (agents/search)
- `Liner Search` = 공식 신고 창구 링크 (tools/search/web)
- `규칙 엔진` = 심각도·기한·타임라인 (LLM 없이 동일 결과)

**촬영 시 주의**
- 네트워크가 느리면 Search Agent가 30초 안팎 걸립니다. 컷 편집으로 "확인 중" 장면을 넣으면 오히려 실제 동작으로 보입니다.
- 직접 붙여넣기가 번거로우면 **[▶ 단계별 재생]** 으로 같은 5단계를 자동 입력할 수 있습니다(단계 사이 약 1초, Liner 연동 시 응답 대기 포함). 심각도 P3 → P2 → P1 전환이 상단 트레일과 대화 알림으로 보여 "격상" 장면을 편집 없이 잡을 수 있습니다. 재생 중 버튼을 다시 누르면 멈춥니다.
- [한 번에 실행]은 결과만 보여 주므로 컷 전환용으로만 쓰세요.
- 문서 장면에서는 통지문의 **"여기부터 내부 검토용 — 발송 전 삭제"** 구분선과 `〔미확인: …〕` 칸을 짚어 주면 "지어내지 않는다" 원칙이 화면으로 보입니다.
- 실제 회사명·계정·고객 정보가 화면에 잡히지 않게 하세요.
