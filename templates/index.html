    자주 묻는 것
    
        
    
          
    로그가 뭔지 몰라요.
    괜찮습니다. 본 것과 시각만 말해도 타임라인이 만들어집니다. [증거 확보] 탭에서 쓰는 메일·PC 환경을 고르면 무엇을 캡처할지, 업체에 보낼 요청 메일까지 알려 줍니다.
    
          
    시계는 언제부터 도나요?
    사건을 시작하는 순간 '지금'을 기준으로 바로 돕니다. 실제로 더 일찍 알았다면 시계 아래 [인지 시각 수정]으로 고치세요 — 법정 기한은 '처음 안 시각'부터 계산됩니다.
    
          
    잘못 말했어요.
    다시 말하면 새 내용으로 바뀝니다. 타임라인의 진술은 [삭제]로 지울 수 있습니다.
    
          
    AI(Liner)는 무엇을 하나요?
    판정·기한·할 일은 규칙 엔진이 같은 기준으로 계산합니다. Liner는 상황 설명을 알아듣고, 질문에 출처와 함께 답하고, 법령 근거와 업체 안내를 찾습니다. 보내기 전에 이름·전화·계좌 같은 개인정보는 가립니다. 오른쪽 위 [Liner 연동]을 누르면 API 5종을 어디서 어떻게 쓰는지와 이 사건의 실제 호출 기록이 나옵니다.
    
          
    신고도 대신 해 주나요?
    아니요. 신고서·통지문 초안까지 만듭니다. 최종 판단과 제출은 담당자가 합니다. 급하면 KISA 118(무료·24시간)에 전화하세요.
    
          
    입력한 내용은 어디에 저장되나요?
    서버 데이터베이스에는 저장하지 않습니다(처리하는 동안만 서버 메모리를 거칩니다). 사건은 이 브라우저에 자동 보관돼 창을 닫아도 첫 화면 '진행 중인 사건'에서 이어 할 수 있고, [저장·공유]에서 사건 파일로 내려받아 다른 PC에서 열 수 있습니다. 함께 쓰는 PC라면 [저장·공유] → [이 PC에서 지우기].
    
          
    이 일을 어떻게 하는지 모르겠어요.
    할 일 옆 [어떻게?]를 누르세요. 준비물·순서·전화할 때 할 말이 나옵니다. 안내가 없는 일은 Liner가 사건 상황에 맞춰 찾아 줍니다.
